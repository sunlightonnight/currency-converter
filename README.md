# Currency Converter

A simple currency converter in Python. Uses the ExchangeRate API to get live exchange rates.

Простой конвертер валют на Python. Использует API ExchangeRate для получения актуальных курсов.

---

## How to run / Как запустить

1. Install Python 3 and the `requests` library: `pip install requests`
2. Download `currency_converter.py`.
3. Run in terminal: `python currency_converter.py`

1. Установи Python 3 и библиотеку `requests`: `pip install requests`
2. Скачай `currency_converter.py`.
3. Запусти в терминале: `python currency_converter.py`

---

## Commands / Команды

- Enter currency code (USD, EUR, KZT) or `EXIT` to quit.
- Enter the amount.
- The program converts to RUB.

- Введи код валюты (USD, EUR, KZT) или `ВЫХОД` для выхода.
- Введи сумму.
- Программа переведёт в рубли.

---

## Example / Пример

Введите код валюты (USD, EUR, KZT) или 'ВЫХОД'
Введите валюту: USD
Введите сумму в USD: 100
100.0 USD = 8512.50 RUB
